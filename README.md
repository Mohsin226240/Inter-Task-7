 Product Landing Page
A clean, modern, and 
fully responsive Product Landing Page built using HTML5, CSS3, and JavaScript.  
Showcases product highlights, pricing plans, and testimonials with smooth interactivity and responsive design.

 sections
 Header / Navigation
  - Logo + navigation links
  - Responsive hamburger menu for mobile
  - Sticky nav on scroll (bonus)

- Hero
  - Product name + tagline / short description
  - Primary CTA (e.g., “Buy Now” or “Get Started”)
  - Hero image or illustration

- Features
  - At least 3 product feature cards
  - Each card includes icon, title, short description
  - Grid / card layout

- Pricing
  - At least 3 pricing plans
  - Plan name, price, feature list, CTA button
  - Highlighted “Recommended” plan (optional)
  - Monthly/Yearly toggle with JS (optional)

- Testimonials
  - 2–3 customer reviews
  - Each review: name, role, text, and optional avatar
  - Testimonial carousel/slider (optional)

- Footer
  - Contact info
  - Social media links
  - Copyright

Interactivity & Enhancements
- Hover effects on buttons, cards, and links
- Smooth scroll navigation
- Animated feature/pricing cards on scroll (CSS keyframes or AOS.js)
- Interactive CTA button hover states
- Bonus: Dark/Light mode toggle  
- Bonus: Testimonial slider  

Tech Stack
- HTML5 for semantic structure  
- CSS3 with Flexbox & Grid for responsive layouts  
- JavaScript for interactivity (scroll, toggles, slider, validation)  

Responsiveness
- Works seamlessly on **desktop, tablet, and mobile**  
- Consistent color scheme, typography, and spacing
